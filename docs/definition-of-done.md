# Definition of Done - Legyen Ön is Milliomos!



Egy feladat (Task/User Story) kizárólag akkor tekinthető befejezettnek (Done), ha az alábbi feltételek mindegyike maradéktalanul teljesül:



1. Build és Futtathatóság:

   * A forráskód lokálisan hibamentesen lefordul Maven/Gradle segítségével.
   * A JavaFX alkalmazás elindul, a megvalósított új funkció nem dob kezeletlen futásidejű kivételt.



2. Kódminőség és Konvenciók:

   * A kód követi a standard Java elnevezési konvenciókat (camelCase, PascalCase, csomagstruktúra).
   * Nincsenek benne felejtett debug üzenetek, felesleges kommentek vagy kikommentezett kódrészletek.
   * Az FXML fájlok és a hozzájuk tartozó Controller osztályok logikailag tisztán elválnak.



3. Verziókezelés (Git workflow):

   * A fejlesztés külön feature ágon történt.
   * A commit üzenetek informatívak és a megállapodott formátumot követik (conventional commits).



4. Kódátvizsgálás (Review):

   * Legalább egy csapattárs átnézte és jóváhagyta az elkészült feladatot.
   * A merge során felmerülő konfliktusok feloldásra kerültek.



5. Projektmenedzsment szinkronizáció:

   * A Kaneo kártya státusza Done-ra lett állítva.
   * Ha a módosítás architektúrát vagy közös komponenst érintett, a dokumentáció frissítésre került.
